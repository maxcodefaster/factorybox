# Factorybox v0.1.0-beta.1

This is the first public beta of the standalone Factorybox runtime. It provides system-container
start, checkpoint, fork, pause, resume and recovery, plus the Open Software Factory consumer
integration and a small prepared pool. IDEs and Dev Containers consume the runtime without owning
its lifecycle.

Linux on arm64 is the one verified platform. The published worker image passed the native
conformance on a single-node Kubernetes cluster, and Open Software Factory ran its install, upgrade
and soak checks on it. amd64 and Azure AKS are not supported yet. The worker needs what a standard
Linux Kubernetes node offers: cgroup v2, 4096-byte pages and local persistent storage. Kernel
admission is by capability, and the worker names a missing capability in its own report. Use
separate workers for different customers or trust domains. See the
[current readiness checklist](../first-release-status.md).

Original Factorybox code uses Apache-2.0. Sysbox and CRIU retain their original
terms. Distribution includes the exact component source archive and provenance;
see [LICENSING.md](../../LICENSING.md).

The release gate checks the delivered image version and license, CRIU core,
Sysbox unit and integration tests, lifecycle and systemd Bats tests, all fourteen
worker suites, planned and abrupt worker replacement and both Factory consumer
lanes. Failed or unrun required gates block qualification.
The native gate receipt identifies the exact image and package.

The 24-hour endurance run, larger repeated-run series, broader host qualification
and further performance work follow this beta. Existing timing results
describe older exact packages and do not promise this beta's latency or p95.

## Upstream maintenance

Keep Sysbox and CRIU pinned. Review upstream changes monthly and before a
release, prioritizing security fixes and changes to namespaces, cgroups, mounts
and checkpoint/restore. Record the reviewed commits and the decision to adopt or
defer. Updating a pin requires the relevant regression and native gates.

Submit small, generally useful fixes separately, with a minimal reproduction,
the regression test, original attribution and the upstream contribution process.
Factorybox-specific orchestration stays here. AI-assisted authorship does not
replace review or tests and is not by itself a reason to rewrite working code.
No upstream submission is part of publishing this beta.
